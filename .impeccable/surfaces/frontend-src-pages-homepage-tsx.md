# Home — public homepage

## Surface

Route `/` in the frontend app, rendered to an unauthenticated visitor with the API down. Mode: Persuade. Audience: the office that runs hostel allocation (wardens, deans of student affairs, housing officers). Action: understand what a run is, trust the output, then open the desk at `/login`. Success: a visitor who leaves after one viewport can describe the four boundaries, the human gate and the sample run without signing in. Untouched: every signed-in route, the admin console, `frontend/demos/`, the backend.

## Strategy

One continuous argument, in order: a run happening → four hard boundaries → compatibility inside a boundary → four artifacts a run leaves → the floor (not the average) → a person signs → what it does not do → the desk. The hero demonstrates cause and effect with a deterministic seeded pipeline (96 marks, 4 segments, 1,104 pairs, 38 rooms, 4 documents) instead of explaining an idle interface. Every number on the page is read from that one simulation. Persistent thread: a hairline margin rule with a wax tick tracking scroll progress, on a page built as one document.

## Direction contract

THESIS: A lit desk in a dark room: the argument is a document being made under a lamp, and the visitor watches a sample run mark, cut, pair and file itself. It refuses the category default of an idle admin screenshot with feature cards under it.

OWN-WORLD: Near-black forest-green field warming as the page descends; aged cream paper as the object layer; oxblood wax as the mark layer; amber reserved for at-risk and attention. Fine engraved hairline texture and one real pool of light, never a repeating grid. Besley variable serif for display, IBM Plex Mono for data and labels, Public Sans for body. Soft, generous radii on every control; paper rectangles keep small radii and real edge shadows.

STORY: The visitor understands that four boundaries cut the cohort before any compatibility, that rooms are scored and explained, that a run leaves assignable documents, and that the weakest student — not the average — is reported and signed off by a person. They open the desk.

FIRST VIEWPORT: A slim dark header with the Roommate Matcher wordmark and one wax "Open the desk" control. Left: a mono masthead line carrying "Roommate Matcher · Room allocation desk" above the claim "A room list you can sign." at display scale, one sentence naming the audience, a two-sentence account of a run, and the primary and sample-run actions. Right: a tall cream run sheet where 96 answer marks arrive over ghost shelves and room outlines, settle into four labelled segment shelves, gain room boxes and pair edges, and fan four documents, resting in a legible finished state with a replay control. A warm light pool sits behind the sheet.

FORM: pinned whole by the brief; no roll. `seed: none (pinned)` — "Material world: a lit desk in a dark room… Deep forest-green field… aged cream paper as the object layer, oxblood wax as the mark layer, amber reserved for at-risk / attention." and "Secondary: a sample run that plays on this page" with "a live visual that actually executes a pipeline: 96 answer marks arrive → four boundaries cut the cohort into four segments → pairs form (and visibly hold) → four documents fan out." The brief also pins the argument order, the motion programme and the exact sample-run arithmetic.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance.
